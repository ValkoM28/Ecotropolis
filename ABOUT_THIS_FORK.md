# About this fork

This is a fork of **Ecotropolis**, a first-semester project from the E24 semester of the
Software Engineering programme at SDU Sønderborg.
Original repository: https://github.com/jonathank1906/Ecotropolis

## Why this fork exists

The code is used as the worked example in the internal
**"Understanding Code with AI"** guide for the 1st semester students at SDU.
The guide cites specific files and line numbers, so **the code in this fork is
deliberately left unchanged**. Please don't edit the existing files. If you want to
experiment, make your own copy or branch.

## Using it with the guide

- The code is a text-based C# console game about sustainability and urban planning.
- To run it you need the .NET SDK (see `WorldOfZuul.csproj` for the version). Then run `dotnet run` in the repository root.
- The original `README.md` contains only the project title. The guide relies on that, so it hasn't been changed.
